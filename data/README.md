# data/

PhysioNet records are **not** stored in the repository. Download them with

```
python3 download_data.py
```

This creates `100.hea`, `100.dat`, `100.atr` (MIT-BIH Arrhythmia Database, record 100) and
`em.hea`, `em.dat` (MIT-BIH Noise Stress Test Database, electrode-motion noise) in this folder.
